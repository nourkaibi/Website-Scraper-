About This Project

Hacker News Monitoring Dashboard is a web application that collects live stories from the Hacker News API, organizes them by technology-related categories, detects matched keywords, and displays the results in a clean interactive dashboard.

The dashboard helps users quickly understand what topics are trending, compare story categories, search articles, and export the collected data as a CSV file.

Source: Hacker News API

All data is fetched in real time from Hacker News and processed by this dashboard.
