Functional flow

How the scraper processes stories

The dashboard follows a simple pipeline from story collection to classification, prioritization, visualization, and export.

1. Collect

Fetch top stories from the Hacker News API.

2. Extract

Store title, author, score, comments, time, and external link.

3. Classify

Assign categories using manually selected rule-based keywords.

4. Prioritize

Mark stories as High, Medium, or Low priority according to thresholds.

5. Visualize

Display summaries, charts, top keywords, and table results in the dashboard.

6. Export

Download all records or only the filtered result set as CSV.
